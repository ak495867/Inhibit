# Wider PIT Plot QA Notes

The wider PIT block-bootstrap Sharpe histogram renders with readable labels, observed-Sharpe marker, and 2.5%/97.5% interval markers. The distribution is broad and visibly overlaps negative and positive Sharpe values, which is consistent with the reported interval spanning below zero.

The wider PIT walk-forward plot renders five factor curves over 13 held-out windows with a readable legend and zero reference line. All curves show substantial cross-window variation: several positive windows are followed by negative windows, and the curves move together during some market regimes. This does not support a claim of stable alpha by itself.
